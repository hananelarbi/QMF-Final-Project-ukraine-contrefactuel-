# Counterfactual Inflation Analysis: Ukraine and Euro Area Membership

## Overview

This project is part of the *Quantitative Methods in Finance* final exam (2025–2026).

The objective is to construct a counterfactual analysis of Ukrainian inflation under a hypothetical Euro Area membership. The project combines economic reasoning and econometric modeling to assess how inflation dynamics would have differed under a common monetary policy.

## Methodology (preview)

The econometric strategy will involve:

- Constructing an inflation panel (Euro Area + Ukraine)
- Extracting a common inflation factor using PCA
- Estimating Ukraine’s inflation sensitivity to the Euro Area factor
- Building a counterfactual inflation path
- Comparing actual vs. counterfactual inflation
